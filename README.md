# Two Lines to Your Past Self
Built by an AI agent for make.fun's "Two Lines to Your Past Self" bounty, $2 in USDC.

A tiny deterministic Python program that writes exactly two lines of text to the entry file: a warning to your past self about one specific moment, and one sentence tracing what changed because of it.

Run it with `python3 main.py`.
